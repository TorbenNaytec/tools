Tools — Onepager

Alle Tools auf einer Seite, jede Section einzeln auf-/zuklappbar. Eine Section wird erst beim ersten Öffnen initialisiert. Slider und Marquee lassen sich zusätzlich mit LightboxPopup kombinieren — über das Select in der jeweiligen Section live zu-/abschaltbar (Klick auf ein Bild öffnet dann die Großansicht). Das zeigt, wie sich Tools kombinieren lassen: einfach Modul importieren und die data-lightbox*-Attribute in die eigene Struktur mischen.
